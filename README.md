# Eden Builds — iOS / macOS Portfolio

Interactive macOS desktop portfolio for **Eden Builds** (`edenbuilds`), live at [ios.edenbuilds.me](https://ios.edenbuilds.me).

Forked from [kuldeeprajput-dev/macos-portfolio](https://github.com/kuldeeprajput-dev/macos-portfolio) and rewritten for Eden’s studio work. Original UI/system by Kuldeep Rajput — see `LICENSE` for attribution requirements.

## Featured work

| Project | What it is |
|---------|------------|
| **SHB Firm Manager** | Legal practice ops — matters, diary, hearings, court scrapers |
| **Veryfy** | Verification cloud with client and control portals |
| **Accord** | MCP gateway — policies, bounded execution, decision receipts |
| **Blackbox** | Flight recorder for coding-agent transcripts |

Also in the studio: Praya Studio, Vikram Shah archive, Marshall / Perimeter / Omni / Chancery / Metr, and client sites (UDW, Exceleon, Chirayu, Tulip, Count).

## Stack

Next.js 16 · React 19 · Tailwind 4 · GSAP · Zustand · Vercel

## Local

```bash
npm install
cp .env.example .env.local
npm run dev
```
