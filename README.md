# Omkar — iOS / macOS Portfolio

Interactive macOS / iOS desktop for **Omkar** (`edenbuilds`), live at [ios.edenbuilds.me](https://ios.edenbuilds.me).

Built as a personal machine: real projects from GitHub, studio copy, and Omkar's photos — not a generic demo skin.

## Featured work

| Project | What it is |
|--------|------------|
| **SHB Firm Manager** | Legal practice ops — matters, diary, hearings, court scrapers |
| **Veryfy** | Verification cloud with client and control portals |
| **Accord** | MCP gateway — policies, bounded execution, decision receipts |
| **Blackbox** | Flight recorder for coding-agent transcripts |
| **Agentloop** | Portable agent harness — council, swarm, ship gates |
| **Arya AI** | Indian-law drafting helpers with verification gates |
| **Bloom** | On-device camera gesture UI |
| **Vikram Shah Archive** | Public reading copy of legal papers |
| **GenOffice** | AI-native office suite (macOS / Windows) |
| **Metr** | macOS menu-bar companion for AI usage windows |

Also in the studio: Hunk, Touchline, Enzo, Bharat Courts, Marshall / Perimeter / Omni / Chancery, and client sites (UDW, Exceleon, Chirayu, Tulip, Count).

## Stack

Next.js 16 · React 19 · Tailwind 4 · GSAP · Zustand · Vercel

## Local

```bash
npm install
cp .env.example .env.local
npm run dev
```
